# AI 추천 채팅앱

## 프로젝트 개요  
이 프로젝트는 AI가 사용자에게 맞춤형 채팅 경험을 추천해주는 혁신적인 채팅 애플리케이션입니다.  
사용자의 대화 패턴과 관심사를 분석해 최적화된 채팅방, 대화 상대, 또는 메시지 템플릿 등을 제안합니다.

## 주요 기능  
- **AI 기반 추천 시스템**: 사용자의 대화 스타일과 관심사를 분석해 맞춤형 채팅방 및 친구 추천  
- **실시간 채팅**: 빠르고 안정적인 메시지 전송 및 수신  
- **읽지 않은 메시지 표시**: 안 읽은 메시지 개수를 실시간으로 보여줌
